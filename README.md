📌 Sobre o projeto

Este projeto faz parte de um desafio educacional da Digital Innovation One (DIO), com o objetivo de estudar os conceitos de criptografia e descriptografia de arquivos utilizando Python.

O laboratório busca demonstrar, de forma controlada, como operações criptográficas podem afetar a disponibilidade dos dados e por que o gerenciamento seguro de chaves é fundamental para a Segurança da Informação.

🎯 Objetivos

Estudar os fundamentos da criptografia de arquivos.

Compreender o funcionamento conceitual de ransomware.

Praticar programação em Python.

Documentar procedimentos técnicos.

Utilizar Git e GitHub para versionamento.

Conhecer medidas defensivas contra ataques de ransomware.

🧰 Tecnologias utilizadas

Python 3

Bibliotecas criptográficas apropriadas

Linux Ubuntu

Git

GitHub

🔐 Conceitos estudados

Criptografia

A criptografia transforma informações legíveis em dados protegidos por meio de algoritmos e chaves criptográficas.

Descriptografia

A descriptografia permite recuperar os dados quando se dispõe da chave correta e dos parâmetros necessários.

Ransomware

Ransomware é uma categoria de malware que pode impedir o acesso a arquivos ou sistemas, frequentemente por meio de criptografia, e exigir pagamento para tentar restaurar o acesso.

🧪 Ambiente de laboratório

Os experimentos devem utilizar exclusivamente arquivos fictícios, armazenados em uma pasta de teste isolada.

O projeto não deve modificar documentos pessoais, arquivos do sistema operacional ou dados de terceiros.

🛡️ Medidas defensivas

Manter backups offline ou isolados da rede.

Testar periodicamente a restauração dos backups.

Manter sistemas e aplicações atualizados.

Aplicar o princípio do menor privilégio.

Monitorar alterações incomuns em arquivos.

Utilizar soluções de proteção de endpoints.

Implementar autenticação multifator.

Treinar usuários contra phishing e engenharia social.
